# ⚙️ Manufatura Eletrônica News

Portal estático que agrega notícias sobre **manufatura eletrônica**, exibindo em tempo real os principais destaques de sites especializados do Brasil e do mundo. Desenvolvido com **HTML, CSS e JavaScript puro**, sem necessidade de backend.

---

## 🚀 Funcionalidades

- 📡 Agregação de feeds RSS de portais renomados do setor
- 🎨 Layout responsivo em cards (mobile-first)
- 🗂️ Filtro por categorias (Geral, Embarcados, Indústria, Projetos, Semicondutores)
- 🔄 Atualização automática a cada carregamento da página
- 🌐 100% estático – pronto para GitHub Pages

---

## 📰 Fontes de notícias

Atualmente o portal agrega conteúdo dos seguintes sites:

| Fonte                  | País     | Categoria      |
|------------------------|----------|----------------|
| Inovação Tecnológica   | Brasil   | Geral          |
| Embarcados             | Brasil   | Embarcados     |
| Electronics Weekly     | Reino Unido | Indústria   |
| All About Circuits     | EUA      | Projetos       |
| EETimes                | EUA      | Semicondutores |

> Para adicionar novas fontes, basta editar o array `feeds` no arquivo `script.js`.

---

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript (ES6+)
- [RSS2JSON](https://rss2json.com) – API gratuita para conversão de feeds RSS em JSON
